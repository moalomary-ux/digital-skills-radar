## 1. ما المنتج؟ ولمن؟

منصة ويب ثنائية اللغة (عربي RTL / إنجليزي) مستوحاة من رادار GovTech لهيئة الحكومة الرقمية، لكنها ترصد **مهارات الإنسان** بدل التقنيات. سؤالها المنظم: «كيف يتغير العمل الحكومي، وما القدرات التي يحتاجها الموظف والقيادي، وكيف نطوّرها لإنتاج خدمة وقرار وأداء أفضل؟»

**الجمهور الأساسي:** موظفو وقادة الجهات الحكومية (5 مسارات: توعوي ← أساسي تطبيقي ← تخصصي ← قيادة فرق وتحول ← تنفيذي واستراتيجي).
**الجمهور الثانوي:** الأفراد والطلاب (خدمة عامة: مستكشف مستقبل المهن واختبار التوجيه).

## 3. المعمارية التقنية

### الصفحات (`src/views/` — 16 صفحة)

الرئيسية، تقييم المهارات (Wizard: مسار ← 8 مجالات عبارات ← 8 مواقف حكم ← معايرة)، النتائج (4 طبقات دليل)، مسارات التطوير، مهارات المستقبل، اكتشف التخصصات، اختبار التوجيه، الخريطة التفاعلية، رادار التقنيات، الأدوار الوظيفية، سجل المهارات، المعايير والتقارير، المنهجية، للجهات الحكومية، أثر تمكين الجهات، القطاعات الحكومية، دليل الجهات، تفاصيل الجهة.

### الرسوم البيانية
كلها SVG مبنية يدوياً (`components/`): رادار المهارات المزدوج/الثلاثي، رادار التقنيات (حلقات TRL)، الخريطة الشبكية، الرسوم الشريطية — كلها تراعي RTL و`prefers-reduced-motion` وأداء transform/opacity فقط.

## 4. خط أنابيب البيانات الرسمية

**المصدران:** `inbox/services.xlsx` (خدمات الهيئة للجهات) و`inbox/sectors.xlsx` (دليل القطاعات والجهات والشعارات) — ملفان رسميان زوّدنا بهما المستخدم.

- **`build_gov_data.py`**: استخرج 486 صورة شعار مضمنة من sectors.xlsx (مطابقة 1:1 مع صفوف «يوجد شعار»؛ 485 ملفاً فريداً بعد كشف تكرار واحد) + بنى مجموعات الجهات/القطاعات/الخدمات. **معدل مطابقة الأسماء بين الملفين: 421/421 = 100%** (تطبيع الهمزات والتاء المربوطة).
- **`build_sector_skills.py`**: بنى مصفوفة جهة×فئة من 1,597 سطر تفصيل (372/372 جهة استشارية، 322/322 تدريبية) — المجاميع تتطابق تماماً مع إجماليات الجداول.
- **ملاحظة أمانة موثقة:** نص المنهجية في الملف الأصلي يقول 7,935/2,918 بينما مجاميع جداوله نفسها تؤكد **7,915/2,873** — اعتمدنا الموثق حسابياً ووثقنا الفرق في الكود وصفحة المنهجية.
- تقرير النسب الكامل: `skills-radar/src/data/govData.report.md`

## 5. أساس الأدلة

- **الأطر:** SFIA 9 (الإطار الوطني السعودي مبني عليه — 102 مهارة)، DigComp 2.2/3.0، UNESCO DLGF، ESCO، ITU — مع جدول تقابل مستويات موثق في صفحة المعايير.
- **التقارير:** WEF Future of Jobs 2025 (170M/92M/39%، قوائم النمو/الاندثار حرفياً)، ILO 2025 (تعرض GenAI)، McKinsey، OECD (إطار المواهب الرقمية 2021/2024)، UN E-Gov 2024، Coursera GSR 2025/2026 (تسجيلات GenAI السعودية +165%)، LinkedIn Skills on the Rise 2025.
- **المؤشرات العالمية المربوطة:** GTMI (البنك الدولي)، OECD DGI، OURdata، UN EGDI/OSI، ITU GCI، IMD للتنافسية الرقمية.
- **قاعدة المحتوى:** «لا رقم بلا مصدر» — كل ادعاء كمي يحمل حقل `source` يُعرض في الواجهة مع شارة ثقة (تقرير دولي/مصدر رسمي/استطلاع/ذاتي الإبلاغ).

## 7. التشغيل والنشر

```bash
cd skills-radar
npm install        # مرة واحدة
npm run dev        # تطوير محلي
npm run build      # بناء الإنتاج → dist/
node scripts/levels.selftest.mjs   # اختبار حدودي آلي: 24 تأكيداً
```

**النشر على GitHub Pages:** فرع `gh-pages` يحوي `dist/` فقط + ملف `.nojekyll` + إعداد `base: '/digital-skills-radar/'` في `vite.config.ts`. لإعادة النشر بعد أي تعديل: `npm run build` ثم ادفع محتوى `dist/` إلى فرع `gh-pages` (تحقق من تغير تجزئة الحزمة في الرابط الحي).

**الفحص الذاتي:** `scripts/levels.selftest.mjs` يتحقق من حدود المراحل (0، 1.24، 1.245، 1.25... 4.0) — 24/24 ناجح.

## 8. القيود المعروفة (الصدق المنهجي)

1. مواقف الحكم الأربعون **تحريرية غير متحقق منها ميدانياً** (موثق في المنهجية) — تحتاج تجربة تجريبية n≥200.
2. حدود المراحل (1.25/2.25/3.25) تحريرية غير معايرة إحصائياً — لا تُستخدم للمفاضلة أو التوظيف (ممنوع صراحة في كل الصفحات).
3. أوزان ربط فئات الاستشارات بالمجالات المهارية تحريرية (موثقة في `sectorSkills.ts` وصفحة المنهجية).
4. أكواد ISCO-08 تقريبية (موسومة كذلك في الواجهة).
5. بيانات الأجور والشواغر السعودية غير مدمجة (تحتاج مصدراً رسمياً — موسومة «قريباً»).
6. ترجمات حقول رادار التقنيات تحريرية أمينة — تحتاج مراجعة متحدث أصلي قبل إطلاق رسمي.

## 9. ما ينقص للنشر الوطني (300 جهة)

- بيانات أجور/شواغر رسمية (اتفاقية مع GASTAT/الموارد البشرية)
- برنامج التحقق الميداني السيكومتري (عينة موظفين حقيقية)
- مجلس تحرير خبير دائم + قناة مراجعة عامة
- استضافة رسمية وحوكمة بيانات (PDPL) — المنصة حالياً بلا خادم ولا تجمع بيانات (localStorage فقط)
